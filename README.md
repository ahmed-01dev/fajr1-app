# فَجْر — FAJR

تطبيق أندرويد ي帮助 المسلمين على الاستيقاظ لصلاة الفجر عبر مجتمع موثوق: فرق، رفيق استيقاظ، تذكيرات، وتحفيز.

> ملاحظة: هذا المشروع يُبنى من الصفر في هذا المستودع، ويبقى مستودع FAJR1 القديم دون أي تغيير.

---

## 📱 ما هو تطبيق فَجْر؟

- يساعدك على الاستيقاظ لصلاة الفجر ويساعد غيرك أيضًا.
- انضم إلى فريق أو أنشئ فريقًا.
- ابحث عن رفيق استيقاظ موثوق.
- تابع مواظبتك واحصل على إنجازات محفّزة.

## 🔑 وضعان للتشغيل

1. **الوضع المحلي/التجريبي (demo):** يعمل بدون أي إعداد — شاشات التطبيق، أوقات الصلاة (بعد اختيار مدينة يدويًا)، الأذكار، التفضيلات المحلية. كل ما يحتاج إنترنت يعرض رسالة واضحة "يتطلب Firebase" بدل ادعاء نجاح كاذب.
2. **الوضع السحابي الكامل (Firebase):** حسابات حقيقية، فرق، رفيق استيقاظ، نقاط XP محمية من الخادم، إشعارات فورية. يتطلب إعداد Firebase (الخطوات أدناه).

---

## 🧪 التحقق من البناء (CI)

كل رفع أو Pull Request يشغّل تلقائيًا من تبويب **Actions**:
1. `analyze-test` — تنسيق الكود، التحليل، الاختبارات.
2. `build-android` — بناء APK و AAB ورفعهما كـ Artifacts.

لتنزيل التطبيق: **Actions** ← آخر تشغيل ناجح (أخضر) ← بالأسفل **Artifacts** ← `fajr-release-apk` ← نزّله وثبّته على جوالك.

## 🔥 إعداد Firebase (اختياري — لتفعيل الوضع السحابي)

1. اذهب إلى console.firebase.google.com واضغط **Add project** وسمّه مثلًا `fajr-app`.
2. من قائمة **Build** ← **Authentication** ← **Get started** ← فعّل **Email/Password**.
3. من **Build** ← **Firestore Database** ← **Create database** ← اختر وضع الإنتاج (production).
4. من **Project settings** ← **Your apps** ← اضغط أيقونة **Android** ← اكتب اسم الحزمة: `com.fajr.app` ← حمّل ملف `google-services.json`.
5. ضع الملف في مجلد `android/app/` (⚠️ لا ترفعه إلى GitHub — مستودعك عام).
6. انشر قواعد الحماية: **Firestore Database** ← تبويب **Rules** ← انسخ محتوى ملف `firestore.rules` ← **Publish**.
7. نشر دوال الخادم (يتطلب حاسوبًا مع Node.js):
   ```
   npm install -g firebase-tools
   firebase login
   firebase deploy --only functions
   ```

## 🛡️ الأمان والخصوصية

- لا يوجد أي طلب لإذن "كل الملفات" (MANAGE_EXTERNAL_STORAGE).
- الأذونات المطلوبة فقط: الإشعارات والموقع (عند الحاجة، مع شرح السبب).
- نقاط XP والإنجازات والتتابعات تُمنح من الخادم فقط — العميل لا يستطيع منح نفسه نقاطًا.
- لا تُرفع كلمات مرور أو مفاتيح أو ملفات حساب خدمة إلى GitHub أبدًا.
- ملف `PRIVACY_POLICY.md` يشرح ما تتم مشاركته مع الرفقاء والفرق.

## 🧰 التشخيص إذا فشل البناء

1. افتح تبويب **Actions**.
2. اضغط على التشغيل الأحمر.
3. افتح الخطوة الحمراء واقرأ آخر الأسطر.
4. خطأ `Missing google-services.json` = الوضع التجريبي المتوقع، لا يمنع البناء.
